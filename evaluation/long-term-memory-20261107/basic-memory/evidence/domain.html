## our point of view

Models are rented.
Your knowledge is the asset.

The model behind your agents will change every few months, and so will the tools around it. What matters is what your team knows: what you decided, why, and what you've already tried. Today that knowledge lives in fragmented chat histories and vendor memory.

It belongs in one stable, always-accessible place your company owns, that every agent and every person works from.

Basic Memory is where you keep what you know, and where agents and people leave context for each other.

No more re-explaining

New agents, new sessions, and new hires start with the context your team has already built.

Work you can check

Agents work from notes people can open, so anyone can see where an answer came from.

Knowledge that survives change

Swap models, tools, or vendors. Move people between projects. The memory stays.

Owned, with a predictable bill

Plain Markdown you can export anytime, on a flat plan with a spending limit.

## why basic memory

Memory that belongs to you,
not to your tools.

Your AI tools will keep changing. The knowledge you build with them should outlast every one of them, and stay something you and your team can read.

✕Notes apps
Obsidian, Notion, Google Docs
Made for people to write in. AI reaches them through plugins and connectors, one app at a time, and reads whole documents to find one fact, so answers come slower and cost more tokens.
✕Built-in AI memory
Claude or ChatGPT memory
Nice when it remembers your mother's birthday, but of little use for your team's work. The vendor manages it, and it stays behind when you switch tools.
✕Memory APIs
memory services for developers
Built for wiring memory into your own app: an LLM extracts facts into a store your agent queries. Useful, but mostly as a database for machines, not for people and AI working together, or for teams.
✓Basic Memory
files you own + a real index
Plain Markdown that you, your team, and every AI tool read and write, with full-text, semantic, and knowledge-graph search on top, and an editor where your AI's edits, comments, and suggestions show up in real time. Switch tools and your memory comes with you.

## under the hood

Plain files, with real search on top.

A folder of Markdown is easy to own and hard to search. Basic Memory search helps your AI find all the relevant information, not just the notes with matching words.

Semantic search

Find by meaning, not just keywords. Vector and hybrid search across everything you've written.

Structured search

Filter by frontmatter. Status, type, tags, priority, or any custom field. Query your notes like records.

Schemas

Define and validate note types. Task, Person, Client, Ticket. So structure holds as the graph grows.

Knowledge graph

Typed relations and observations connect notes into a graph your AI can actually traverse.

Less reading, faster answers.

In a folder of notes, like an Obsidian vault, an AI reads whole files to find one fact. Basic Memory lets it search first and read only what it needs, which saves time and tokens.

Same question: “What did we decide about Q4 pricing, and why?”

A folder of notes

  1. 1Greps for “pricing” and gets dozens of matches
  2. 2Opens several whole files to check which one matters
  3. 3Misses the note titled “Plans for next year”: different words
  4. 4Next session, starts over

Basic Memory

  1. 1One search, by meaning: the decision and the meeting it came from
  2. 2Reads the section it needs, not the whole file
  3. 3Follows a link to who decided and what changed since
  4. 4Next session, the same search finds the same answer
