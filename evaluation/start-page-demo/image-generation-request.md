## 统一美术方向（四图共同提示词）
为桌面阅读与写作应用 Nozeli 绘制一套四张功能说明插画。精致、克制的编辑器产品插画，简洁的二维或轻微轴测 UI 场景，具有清晰前后层次和少量柔和阴影，不要廉价线框占位图，也不要复杂写实桌面。Slate 深蓝灰、柔和灰白、低饱和浅蓝为主，只用很少的柔和绿色/暖色突出关键交互。没有人物、机器人、脑、魔法棒、发光电路、炫彩渐变、大量装饰。图像主体饱满，画面留白约10%，主体集中且完整，四张同视角、同线宽、同光照、同视觉重量。适合作为深色和浅色 UI 中的独立插画，优先透明背景；不支持透明则使用一致的纯净浅灰底，并明确告知。每张画布 1200×720（5:3），可无损缩小至约320×192；核心动作在约160px宽仍可识别。每图独立文件，不要四宫格拼图。

所有图像内禁止任何文字、字母、数字、品牌、文件名、水印或伪文字；用短横线表示文档内容。中文标题与功能说明由网页另行排版。图片是概念插画，不冒充真实产品截图，不画未实现的自动修改/自动接受结果。

## 图一 annotation-discussion.png — 批注与选区讨论
一份可阅读的论文/文档页面，少量段落线条，其中一段明显但柔和高亮。高亮区域通过短而清楚的连线连接到旁侧局部讨论气泡，气泡内几条简洁回复线。另一处小型手绘圈/笔迹表达可以标出画面位置。突出“围绕原文的具体位置交谈”，不是普通聊天窗口压在文档上。文档与批注必须视觉关联，不画已发送或自动执行成功的勾号。

## 图二 review-loop.png — 任务闭环
阅读者可核对的结果报告页面与候选文档差异视图，几条低饱和红绿改动行。流程连接到清晰的人工审阅节点，再分为两条可辨识路径：接受（小型勾形符号）和反馈继续修改（回环箭头）。两条是可选路径，不画成两条都已成功完成。强调“先看报告和差异，再决定”，不能只画绿色大勾或一条自动成功流水线。

## 图三 split-reading.png — 分屏阅读
一个且仅一个桌面应用外框，同一标题栏内并排三个真实可辨识的内容分区：左为文档线条，中为对话气泡，右为报告/差异摘要。分区通过细分隔线连接成一个连续工作面。三个分区都可读出用途但无文字。不要画三个漂浮窗口，不要画显示器设备。重点“同一窗口并排核对”。

## 图四 detached-windows.png — 独立窗口
两个有各自标题栏的独立应用窗口，前后错位但不遮住关键内容，主窗口中一个分区被延伸为第二个独立窗口。两个窗口间用克制清晰的双向箭头表示移出与返回，窗口中相同高亮内容建立“同一份内容”的关联。不要复制成两份不同文档、不要画网页标签或多个浏览器，不用三个分屏替代此图。重点“原内容跨窗口移动且可返回”。
