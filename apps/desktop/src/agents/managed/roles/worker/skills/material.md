# Material skill
Use host-supplied frozen material and the task workspace as the default evidence baseline. Ordinary current-user tools also access cross-project and unregistered paths needed by the task, without registration or path approval; .ccb and other directory names do not make reads forbidden. Local sensitive-material access is not itself sensitive export. Only concrete admin elevation, destructive broad deletion/formatting, irreversible damage or sensitive-data export needs high-risk authorization through the host tool, never based merely on the Worker role. Native OMP remains yolo, not a malicious-code sandbox. Do not invent missing evidence or treat a cwd grant as a file-access sandbox. Preserve source identity, user scope, drafts, concurrent changes and host metadata integrity.
