# 项目起点与空对话 Demo

追加“继承其他 Agent 工作”：四个主要起点使用两列布局，点击只填入可编辑草稿，要求定位当前项目关联的Provider/Agent本地历史，记录目标、决定、进展、文件、验证、未完成与阻塞及来源。无法确认归属单列待确认，区分旧陈述与当前文件事实，不读取凭据、不自动执行旧指令。该功能在demo中不实际搜索历史、不生成工作记录。已实屏验证填稿不发送、返回保留草稿及390px深色可达、无横向溢出和运行错误。

访问 `/demos/project-start/`（本机静态服务示例：http://127.0.0.1:8874/demos/project-start/）。独立设计预览，不接生产文件、模型、任务或报告流程，不安装发布。

- 空工作区提供打开文件、从对话开始两个入口，无功能图片。
- 空对话提供了解项目、生成分析报告、梳理待办三项起点；更多中含阅读材料、运行方式、项目问题。
- 点击建议只填写草稿，输入后建议让位；显式发送仅展示演示回执，不能当作真实报告。阅读材料须选择示例文件。
- 从对话退出再进入保留本页草稿及消息；已有草稿不被建议覆盖。重置预览显式清空demo状态，刷新页面不保证保留。
- 文件列表为固定示例。亮暗主题及窄屏布局可切换。

实屏验证：1200px空页与对话页、点击建议未生成消息、返回重开保留草稿、更多/材料选择、文件入口、发送预览回执；390px深色无横向溢出、发送按钮可见，未观察到运行错误。仅浏览器demo验证，不是生产Electron能力验收。
