# 当前状态与能力边界

状态基线：`0.1.0-alpha.2`（已发布 Linux Alpha，见[发布说明与发行边界](release.md)）。另有尚未作为发行版发布的 macOS 26.4 arm64 本地候选，已完成六类文件、包内运行时、系统打开和候选间数据回退验证，见[实施记录](macos-implementation.md)。不能把该候选结果归给已发布 tag；Windows、Intel Mac 及其他 macOS 版本未验收。

## 已具备的主要能力（Linux 实测）

- **阅读**：PDF（大纲、搜索、缩放、文本层）；文本／Markdown／TeX／BibTeX；代码文件（Monaco）；图片（PNG/JPEG/WebP）；DOCX；XLSX；PPTX（内嵌 PPTist 编辑，草稿独立保存，导出副本不覆盖原文件）。
- **批注与讨论**：文字选区、PDF 页／选区／区域、图片区域、文档位置右键点锚与画面涂鸦均可就地备注或发起讨论；讨论锚定发起时的版本与位置。保存本地备注不派工，显式发送才交给 Agent。
- **编辑与版本**：自动保存与冲突检测；每文件修改账本与作者标记（你／各 Agent／外部）；历史版本对比（Diff）不改动原文；Agent 修改经宿主精确同步到打开的编辑器，不进入本地撤销栈。
- **统一工作区**：文档与对话共用标签组布局（并排／堆叠／多列／网格）；拖出为真实独立窗口并可移回；快速打开、文件树隐藏／恢复、已打开列表。
- **后台协作**：私有 OMP 三角色（前台／主控／Worker）；后台 Work 以报告＋候选文件差异交付，人显式接受（合入项目）或丢弃（不合入）；接受前不写回原文件。统一待办中心处理问题与成果。
- **终端**：Provider 控制台终端；Linux 系统终端附着（Konsole 为实测目标）；macOS 候选已验证 Terminal.app 附着、中文输入、断开与重连。
- **TeX**：源码旁动态 PDF 预览（latexmk／XeLaTeX／pdfLaTeX／LuaLaTeX 或 Tectonic，需本机工具链）；可选 TexLab 补全。
- **设置**：私有 OMP 源与账号管理、三角色默认模型、外观（主题／配色／字体）、Agent 额度；密钥仅存宿主私有配置，不经读取接口回传。
- **空工作台引导**：无打开文件时介绍批注与选区讨论、任务闭环、分屏阅读、独立窗口，并说明操作路径；打开项目、浏览文件及演示复用既有入口。

## 数据与隐私边界

- 项目内容与批注保存在项目目录的 `.nozeli/` 下；应用状态在操作系统用户数据目录。不联网遥测。
- AI 能力使用随应用构建的私有 OMP 运行时（见[OMP 集成](../integrations/omp/README.md)），不读取系统 OMP 配置；模型请求仅在显式操作后发生。
- Git（dugite）随应用捆绑，普通保存不产生提交；接受后台成果才执行受管合入，无自动推送。

## 已知限制（不作已验收声明）

- **平台**：macOS 仅有 26.4 arm64 本地候选验收，支持 `.app` / dmg 装配与 ad-hoc 签名；不包含 Developer ID、公证、自动安装更新或公开发行资格。Windows 未验证。
- **Office 子集**：XLSX 图表与未知 OOXML 部分保留在原包但不显示，格式／结构编辑暂不可写；PPT 图片、转场、母版保真有限，旧 `.ppt` 不支持；Word 批注与作者标记限于正文段落与表格文本。
- **PDF**：批注为页／选区级，锚定保存时的版本；不承诺无损改写任意 PDF。
- **并发写入**：宿主在替换前复核摘要，但不承诺关闭与不合作外部写入者的全部竞态；检测到外部变化时显式提示。
- **依赖与隔离**：TeX 预览／补全依赖本机工具链。普通受管执行以当前用户权限运行，不默认声明沙箱保护；Linux 显式隔离需要 bubblewrap。macOS 显式隔离、系统提权、特殊项目恢复保持不可用，请求会被拒绝；正常重启另有验证。
- **macOS 安全保留**：无法确认归属的进程不终止；无法读取系统受保护进程时，审计标为不完整。文件交换/清理遇到可能的并发内容时保留恢复文件，当前没有自动回收策略，磁盘占用会增长。
- 未承诺：双人文档同步编辑、任意格式截图附件回写、Office 历史二进制还原、跨设备同步。

macOS 的逐项方法、候选摘要及本地证据索引见[实施记录](macos-implementation.md)；生成包、运行 profile 和测试数据库不进入 Git。
