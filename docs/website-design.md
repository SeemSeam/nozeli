# Nozeli 官网首版设计

Date: 2026-11-12
Status: 本地可点击设计原型，待用户审阅；非公网部署、非完整网页版。

## 目标与边界

用户确认先本地设计与验收，再选择域名和托管；首版承担核心功能介绍、预设交互演示和 GitHub 下载导流。不做账号、收费、激活、模型代理、用户论文上传或云端执行，不购买或部署云资源。本轮不修改桌面产品，不安装、不提交、不发布。

- [单文件原型](demos/website/index.html)：无 npm、构建步骤、外部字体或脚本，可直接打开本地文件。
- 本机预览：<http://127.0.0.1:18765/>，仅在开发机服务存活时有效，不是公网地址。
- [桌面长页](demos/website/desktop.png)、[手机长页](demos/website/mobile.png)：实际 Chromium 渲染，非桌面应用截图。

## 核心信息结构

1. 首屏：主标题“让阅读中的想法，接着往下做。”；简介说明阅读、批注、讨论与审阅。主入口交互演示，次入口下载。工作面是 HTML 重绘示意，不冒充真实截图。
2. 三项核心价值：疑问留在原文旁；显式发送时带着材料讨论；修改可比较、由用户决定。明确保存批注不派工、交付不等于接受。
3. 交互演示：原创研究方法笔记→标记段落与本地批注→预设问答→原文/候选对照→模拟采用或查看继续修改示例。用户可自由跳章节和重置，无自动播放。
4. 连续工作面：介绍材料、编辑、分屏、任务与审阅的关系，不展示 Agent 调度架构或内部协议。
5. 下载区：固定到核实的 Beta.3 发布页，Linux x64/macOS arm64，非稳定版；不生成 Windows 假下载按钮。
6. FAQ：演示边界、自备模型账号、材料外发与版本限制。

## 交互合同

- 批注允许用户编辑，保存仅在当前页内存；刷新和重置清空。空白批注不显示保存成功。
- AI 回复和候选均为预设，不根据用户批注生成。页面显式说明；不开放假通用聊天框。
- 模拟采用只更改演示状态并禁用重复按钮；不写任何真实文件。“继续修改”明确为静态说明，不伪造第二轮结果。
- 本页没有上传、模型请求、统计、Cookie 或持久化。点击 GitHub 会离开本站并进入第三方服务，不对第三方数据行为作承诺。
- 下载链接使用 `target=_blank` 和 `rel=noopener noreferrer`。版本、平台和发行说明统一指向同一个固定发布版本。
- 本轮通过 GitHub Releases feed 核对 Beta.3 存在和双平台描述：<https://github.com/SeemSeam/nozeli/releases.atom>。`releases/latest` API 返回404，因此未使用 latest 地址；不将旧本地指南的 Linux-only 结论外推到最新发布。
- 发布页记录仍含再分发义务未签收边界；页面不把发布视为合规认证。

## 实际验收

Linux 环境 Chromium 浏览器实测（不代表 Windows/macOS 浏览器或真实手机验收）：

- 1440×1000 桌面及390×844手机尺寸实际渲染并查看截图；两者文档宽度等于视口宽度。320px额外检查无横向溢出。
- 点击标记段落→编辑批注→保存→预设问答→差异→模拟采用→继续修改说明→重置→自由切章，桌面全程通过；手机尺寸完成批注/讨论/采用/重置。
- 文本框 Tab 到保存按钮、Enter 保存通过；空白批注提示先填写。
- 重置后批注输入区收起、回到首章、采用按钮恢复；刷新重建初始状态。
- 页面错误记录为空。初轮发现favicon404，添加内联图标后刷新网络记录仅本站HTML200，无外部子资源或模型请求。
- `file://` 直接打开并完成模拟采用通过。页面无构建链，因此未运行生产产品构建或测试套件。
- 下载按钮目标核对为 `https://github.com/SeemSeam/nozeli/releases/tag/v0.1.0-beta.3`。未在本轮下载或安装软件，不把链接核对计作安装验收。
