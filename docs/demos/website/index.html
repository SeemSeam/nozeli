Not just another chat window

不是把论文丢进聊天框，
而是让协作留在阅读现场。

你可以停在一句话、一张图、一个疑问上，也可以把它继续变成一份具体的修改。上下文不必靠反复复制来维持。

01 / READ & ANNOTATE

疑问，留在它出现的地方。

在文档中阅读、标记与批注。需要讨论时，围绕选段或区域继续，而不是先离开材料、重新解释一遍。

02 / DISCUSS & CONTINUE

带着原文，接着问下去。

显式发送后，材料随问题交给 AI。可以解释、追问，也可以提出修改要求；保存本地批注本身不派工。

03 / REVIEW & REFINE

修改可比较，决定在你。

查看候选与原文的差异，提出下一轮意见，再决定是否采用。已交付不等于已接受，旧版本也不会被新结果悄悄替换。

Before you start

先了解这几件事。

网页演示和桌面版有什么区别？

网页只重绘关键交互，所有 AI 内容和修改结果均为预设，不读取你的文件、不派任务。真实文件处理、模型配置和成果写入都发生在桌面应用中，能力取决于具体版本。

没有模型账号，也能使用吗？

网页演示不需要模型账号。桌面版普通阅读、批注与编辑可以不配置 AI；使用真实 AI 协作，需要自己的可用模型账号或 API，费用及可用性由所选服务决定。

材料会被上传吗？

这个演示没有上传或模型接口，不收集批注正文。桌面版数据以本地项目为基础；启用 AI 后，材料会按实际功能和请求交给所选模型服务，不应理解为永不联网或绝不外发。

现在应该下载哪个版本？

本设计核对的公开版本为 0.1.0-beta.3，包含 Linux x64 和 macOS arm64，非稳定版。请根据自己的系统，在对应 GitHub 发布页查看使用说明、已知问题与许可边界；当前网页设计不证明安装包可用性。
