# 自动播放教学设计

本轮重设计的是应用内自动教学，不是视频剪辑。目标是让首次使用者先理解工作台，再完成一条连贯的材料协作流程。

## 流程

1. **认识工作台**：项目入口、文件导航、中央工作区、项目对话、工作与待办。先展示真实区域，再解释职责；不自动发送模型请求。
2. **从 Markdown 开始**：打开 `research-notes.md`，切换排版预览，亲自编辑并保存。明确本地编辑无需任务审核。
3. **批注与就地讨论**：本地批注 → 选区讨论草稿 → 明确发送 → 同标签续聊；再用一张图说明区域涂鸦。保存与发送区分。
4. **任务审核闭环**：只跟随任务 A，提交 → 成果待办 → 报告 → Markdown版本差异 → 继续修改 → 接受示例结论。教学固定回复不冒充真实Worker执行。
5. **布局拓展**：回到同一Markdown，分屏材料与对话 → 脱离窗口 → 移回主工作区。
6. **更多材料与下一步**：简短展示PDF、Word和PPT，介绍模型设置，退出回到原项目。TeX不插入首次主线，也不假装已有编译工具。

## 自动播放与视觉约束

- 提示只在操作确实完成、目标内容可见之后解释结果；执行中不提前宣称成功。
- 段落长短决定阅读停留（约6.5–12秒）；暂停冻结倒计时，继续不重复已执行写入。
- 章节名明确显示；控制区负责播放/暂停/结束/定位，提示区负责当前目的与操作，不重复整段文案。
- 提示位于底部侧边，不再默认压住正文顶端与标题；窄窗限制覆盖面积并保留滚动，不与控制卡相互覆盖。
- 界面导览聚焦真实项目/文件/工作区/待办区域；用户重新定位到导览步骤时可以重看，不产生编辑副作用。
- 全程使用Markdown主线及Markdown差异材料，旧TXT不作为教学入口。
- 新教材以模板版本/摘要切换，既有教学副本和用户编辑不被静默覆盖。

## 验收

逐步检查：目标区域先可见、提示不遮关键操作、步骤顺序连续、文件身份正确、错误暂停而非假成功。完整自动播放后核对同一任务闭环和窗口往返；另外验证暂停/继续、跳转、退出、窄窗口与明暗主题。截图和录屏是实际界面证据，不以纯布局数值代替可读性检查。
