## 产品方向

Nozeli 是面向阅读与创作的人–Agent 协作工作台：让 Agent 快速推进任务，也让人看懂结果、参与修改、持续掌握项目。

- **独立可用的阅读与编辑**：即使不配置任何 AI，也可以打开本地项目目录，阅读、批注、编辑受支持的文档。
- **同一工作面协作**：文档、选区与讨论在同一界面；从选区、图片区域或画面位置就地发起讨论，问题自带来源位置。
- **后台任务闭环**：前台快速响应与分流，后台 Worker 各自推进整块任务；成果以可阅读的报告与候选文件差异交付，由人审核后明确接受或丢弃。
- **真实文件与版本**：所有修改作用于用户真实的本地文件，保留未保存编辑、并发冲突处理与可回溯的修改历史；接受后台成果前不写回原文件。

首个可发布版本聚焦的核心场景：打开论文项目 → 阅读真实 PDF 与源码 → 多处高亮和笔记 → 就地讨论并要求修改 → 得到可比较的源码变更 → 保存后继续阅读，旧批注和讨论来源可回溯。

## 验证方式概述

- 常规回归使用合成夹具与真实 Electron 宿主，不发起付费模型请求；需要真实模型的检查一律显式启用、由授权者自行运行，不计入常规绿色门槛。
- 平台能力以实际验收为准：当前仅 **Linux x64（Wayland 桌面）** 经过本机验证，不以 Linux 结果推断 Windows/macOS。
- 具体命令、测试分组与安装工具见[桌面开发说明](../apps/desktop/README.md)。
